# SQL Data Analytics Project

## Project Overview
This project focuses on exploring and analyzing sales data using SQL Server to uncover meaningful business insights and support data-driven decision-making.

It builds on a previously developed **SQL Server Data Warehouse Project**, using its structured data as the foundation for performing Exploratory Data Analysis (EDA) and Advanced Analytics.

The project covers data exploration, trend analysis, performance evaluation, customer and product segmentation, and the development of analytical reports.


## Project Components

### 1. Exploratory Data Analysis (EDA)
- Database Exploration
- Dimensions Exploration
- Date Exploration
- Measures Exploration
- Magnitude Analysis
- Ranking Analysis

### 2. Advanced Analytics
- Change Over Time Analysis
- Cumulative Analysis
- Performance Analysis
- Part-to-Whole Analysis
- Data Segmentation
- Customer Report
- Product Report
